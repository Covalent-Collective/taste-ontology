## 0. 무엇이 나오나요

최종 산출물은 **[`_AGENT-SPEC.md`](_AGENT-SPEC.md) 한 장**입니다.
그 한 장을 AI에게 붙여넣으면, AI가 **내 기준으로** 후보를 거르기 시작합니다.

```
판정:      쓴다 / 안 쓴다 / 보류
결정한 축:  어느 축이 이 판정을 만들었나
거리:      내 위치와 몇 칸 떨어져 있나
관계:      계승한다 / 반발한다 / 도구로쓴다 / 같은질문 / 오해된다
근거:      내가 전에 쓴 문장 한 줄
```

**근거가 내 문장이 아니면 그 판정은 버립니다.** 그게 이 키트가 일반 AI와 갈리는 지점입니다.
자세한 건 **[AGENT.md](AGENT.md)** 에 있습니다.

> 에이전트는 대신 **고르지 않습니다.** 후보를 줄이고 이유를 붙여 가져옵니다.
> 마지막 선택은 끝까지 사람이 합니다.

## 1. 온톨로지가 뭔가요

**내 주제가 무엇과 무엇으로 이루어져 있고, 그게 서로 어떻게 연결되는지의 구조**입니다.
어려운 말이지만 들어가는 건 네 가지뿐입니다.

| 구성 | 뭔가 | 예 |
|---|---|---|
| **축** | 양쪽 끝이 둘 다 매력적인 저울 | 계획된 ↔ 우연에 맡긴 |
| **개념 노드** | 그 주제에서 되풀이되는 질문 하나 | "버린 것들이 남긴 것" |
| **관계** | 노드와 노드가 당기고 미는 방식 | A가 B를 **오해한다** |
| **통념** | 다들 믿는데 내가 뒤집으려는 문장 | "독창은 무에서 나온다" |
| **호라이즌** | 지금·다음·오래 걸리는 것, 세 방향 | H1 매출 / H2 검증 / H3 대표작 |
| **큐레이션 축** | 남의 것을 볼 때 쓰는 저울. **포맷과 내용을 따로** | 따라할 수 있나 / 동의하나 |

> **왜 만드나요?** 태그는 "이미 아는 것"을 분류하고, 온톨로지는 **"무엇을 찾아야 하는지"** 를 알려줍니다.
> 축이 있으면 **반대편에 있는 사람**을 일부러 찾게 됩니다. 그게 콘텐츠가 나오는 자리입니다.

> ✍️ **4단계는 "내가 전에 써둔 문장"을 재료로 씁니다.**
> 예를 들어 전에 *"무거운 얘기만 올리면 새 사람이 못 들어온다"* 라고 써뒀다면,
> 거기서 **무게 축 = 가볍게 쪽**이라는 내 위치가 나옵니다. 쓴 문장이 없으면 나올 게 없습니다.
> 그래서 기록이 먼저예요 — [씩씩데이즈에서 66일 기록 시작하기](https://66days.cc)

2. 압축을 풀고 폴더 이름을 **영문 한 단어**로 바꾸세요 — 예: `ontology`

## 6. AI와 잇는 두 가지 방식

**옵시디언 안에는 AI가 없습니다.** 둘 중 하나로 이으면 됩니다.

**① 복붙 (설치 0분, 이 키트는 이것만으로 됩니다)**
`99-Prompts`의 프롬프트를 Claude·ChatGPT에 붙여넣고, 나온 마크다운을 볼트에 새 노트로 저장합니다.

**② 에이전트가 볼트를 직접 읽기**
Claude Code·Hermes 같은 도구는 폴더를 읽고 파일까지 만들어 줍니다.

```
내 볼트는 ~/ontology 야. 01-Ontology/_Ontology-MOC.md 읽고,
비어 있는 칸이 뭔지 먼저 알려줘.
```

> 모임에서 같이 한다면 ①로 하세요. ②는 설치에 20~30분(윈도우는 WSL2까지) 걸려서
> 90분 세션이 설치만 하다 끝납니다. 자세한 건 [오늘 진행 가이드](WORKSHOP.md)에 있습니다.

## 7. 혼자 하면 둘째 주에 멈춥니다

온톨로지는 한 번 만들고 끝나는 게 아니라 **기록이 쌓이면서 고쳐지는 것**입니다.
그런데 혼자 쓰는 기록은 대개 둘째 주에 멈춥니다. 재미가 없어서가 아니라,
**아무도 안 보고 있어서** 그렇습니다.

> 기계에게 말하면 기록이고, 사람에게 말하면 약속입니다.

[씩씩데이즈](https://66days.cc)는 그래서 소셜 저널링 클럽입니다 —

- 매일 한 줄이 쌓이면 → 이 키트의 **4단계 역산 재료**가 됩니다
