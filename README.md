# ssikssik-ontology

**온톨로지 키트** — 내 주제의 개념 지도를 만들고, 그 지도로 사람과 콘텐츠를 찾는 옵시디언 볼트 템플릿.

씩씩 커뮤니티 실습용입니다. 폴더를 내려받아 옵시디언으로 열면 바로 시작할 수 있습니다.

---

## 0. 온톨로지가 뭔가요

**내 주제가 무엇과 무엇으로 이루어져 있고, 그게 서로 어떻게 연결되는지의 구조**입니다.
어려운 말이지만 들어가는 건 네 가지뿐입니다.

| 구성 | 뭔가 | 예 |
|---|---|---|
| **축** | 양쪽 끝이 둘 다 매력적인 저울 | 계획된 ↔ 우연에 맡긴 |
| **개념 노드** | 그 주제에서 되풀이되는 질문 하나 | "버린 것들이 남긴 것" |
| **관계** | 노드와 노드가 당기고 미는 방식 | A가 B를 **오해한다** |
| **통념** | 다들 믿는데 내가 뒤집으려는 문장 | "독창은 무에서 나온다" |

> **왜 만드나요?** 태그는 "이미 아는 것"을 분류하고, 온톨로지는 **"무엇을 찾아야 하는지"** 를 알려줍니다.
> 축이 있으면 **반대편에 있는 사람**을 일부러 찾게 됩니다. 그게 콘텐츠가 나오는 자리입니다.

## 1. 내려받기

1. 이 페이지 위쪽 초록색 **`Code`** 버튼 → **Download ZIP**
2. 압축을 풀고 폴더 이름을 **영문 한 단어**로 바꾸세요 — 예: `ontology`
3. 바탕화면이나 문서 폴더처럼 **찾기 쉬운 곳**에 두세요

> 한글·띄어쓰기가 든 폴더 이름은 나중에 AI 에이전트가 경로를 못 찾는 일이 생깁니다.

## 2. 옵시디언으로 열기

[obsidian.md](https://obsidian.md) 설치 → **「Open folder as vault」** → 방금 그 폴더 선택

> **볼트(Vault)** 는 옵시디언이 쓰는 **폴더 하나**입니다. 그게 끝입니다.
> 안에 든 `.md` 파일이 메모고, `[[이렇게]]` 쓰면 메모끼리 연결됩니다.

## 4. 폴더

```
01-Ontology/     _Ontology-MOC.md  ← 목차. 축과 개념 계층을 여기서 관리
                 _사건-레이더.md    ← 요즘 터진 일을 축으로 시험하는 자리
                 예시-AI와-미래사회.md
98-Templates/    T4-개념.md  T5-통념.md   ← 복사해서 쓰는 원본 (수정하지 않음)
99-Prompts/      P1-온톨로지-빌더-배포용.md  P7-축-위치-역산.md
```

> 인물·인사이트·발행 노트까지 포함한 **전체 볼트**가 필요하면
> [taste-curation-agent](https://github.com/sujinkim89/taste-curation-agent)를 쓰세요.
> 이 키트는 거기에 그대로 끼워 넣어도 됩니다 — 폴더 이름이 같습니다.

## 5. AI 에이전트와 함께 쓰기

프롬프트는 Claude·ChatGPT 어느 쪽에 붙여넣어도 됩니다. 볼트 폴더를 직접 읽는 에이전트
(Claude Code, Hermes 등)를 쓰면 이렇게 시작하세요.

```
내 볼트는 ~/ontology 야. 01-Ontology/_Ontology-MOC.md 읽고,
비어 있는 칸이 뭔지 먼저 알려줘.
```

## 6. 세 가지만 지키세요

1. **축 이름은 내가 쓰는 단어로.** "쨍함"이 "완성도"보다 낫습니다. 남의 단어로 만든 축은 안 씁니다
2. **한쪽 극만 모이면 축이 죽은 겁니다.** 반대편 인물을 일부러 채우세요
3. **모른 건 비워두세요.** `?`와 `미기록`이 그럴듯한 추측보다 낫습니다

> 만든 건 ZIP으로 내려받은 그 폴더가 전부입니다. 계정도, 설치도, 비용도 없습니다.
