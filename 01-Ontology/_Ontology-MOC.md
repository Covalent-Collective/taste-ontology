# 온톨로지 지도 (MOC)

> 이 파일이 온톨로지의 **목차**입니다. 개념 노드는 각각 따로 파일을 갖고,
> 여기서는 **어디에 무엇이 있는지와 축의 내 위치**만 관리합니다.
> [[P1-온톨로지-빌더-배포용]]을 돌린 결과를 여기에 옮겨 적으세요.

## 나의 축 (Axes)

각 축은 **양극단이 둘 다 매력적**이어야 합니다. 한쪽이 분명히 나쁜 건 축이 아니라 주장입니다.
내 위치는 1~5로 표시 (**1 = 극 A, 5 = 극 B**).

| 축 | ← 극 A | 극 B → | 내 위치 | 근거 (내가 쓴 문장) |
|---|---|---|---|---|
|  |  |  | ? |  |
|  |  |  | ? |  |
|  |  |  | ? |  |
|  |  |  | ? |  |
|  |  |  | ? |  |

> 축 이름은 **내가 실제로 쓰는 단어**로 쓰세요. "쨍함", "허술함", "말끔함" 같은 게
> "완성도", "정교함"보다 훨씬 좋습니다. 남의 단어로 만든 축은 나중에 안 씁니다.

> ✍️ 내 위치가 안 채워지는 건 정상입니다. 역산할 내 문장이 아직 적어서입니다 —
> [씩씩데이즈](https://66days.cc)에서 매일 한 줄씩 쌓으면 채워집니다.

> 내 위치를 못 채우겠으면 비워두지 말고 `?`로 두고, [[P7-축-위치-역산]]을 돌리세요.
> 한 칸이 두 값으로 갈리면(작업 단계와 출력 단계가 반대인 경우) **그대로 모순으로 적으세요.**
> 그게 흠이 아니라 콘텐츠가 나오는 자리입니다.

## 관계 지도

`A -[관계]-> B` 형식. 관계 어휘는 다섯 개만 씁니다 —
**계승한다 / 반발한다 / 도구로쓴다 / 같은질문 / 오해된다**

```
[[  ]] -[  ]-> [[  ]]
[[  ]] -[  ]-> [[  ]]
[[  ]] -[  ]-> [[  ]]
```

> `반발한다`와 `오해된다`가 콘텐츠가 가장 잘 나오는 지점입니다.
> **"다들 A라고 하는데 사실 B다"** 구조가 바로 훅이 됩니다.

## 통념 (반박 대상)

`반발한다`·`오해된다`가 **도착하는 곳**은 축이 아니라 통념입니다.
내 입장이 아니라 **뒤집을 문장**을 적어두는 자리이고, 노드로 따로 뺍니다 (양식은 [[T5-통념]]).
