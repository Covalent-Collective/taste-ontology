# 큐레이션 축 — 포맷과 내용을 따로 본다

레퍼런스를 볼 때 묻는 질문이 **둘로 갈립니다.** 섞으면 둘 다 흐려집니다.

| | 포맷 축 | 내용 축 |
|---|---|---|
| **무엇을 보나** | 어떻게 보여주는가 | 무엇을 말하는가 |
| **판정** | 따라할 수 있나 | 나는 여기에 동의하나 |
| **대상** | 구조 · 순서 · 길이 · 목소리 | 태도 · 입장 · 세계관 |
| **속도** | 한 번 보면 안다 | 여러 번 봐야 안다 |
| **결과물** | 다음 편에서 바꿀 **한 가지** | [[_관계-연산자]]의 **다섯 단어 중 하나** |
| **베껴도 되나** | 구조는 된다 | 문장은 안 된다 |

## 왜 분리하나

**"이 영상 좋다"** 는 쓸모가 없습니다. 포맷이 좋은 건지 관점이 좋은 건지 모르니까요.

편집 리듬은 가져오고 싶은데 **그 사람 입장에는 반대**일 수 있습니다.
반대로 관점은 완전히 동의하는데 포맷이 지루해서 못 쓸 수도 있고요.

> 분리하면 레퍼런스 한 편에서 **두 번 건집니다.** 포맷에서 한 번, 내용에서 또 한 번.
> 안 맞는 쪽은 버리면 됩니다.

그리고 **가져오는 범위가 다릅니다.**
포맷은 **분야 밖에서도** 가져올 수 있습니다 — 요리 영상의 구조를 인터뷰에 쓰는 식으로요.
내용은 분야 안에서 찾아야 합니다. 분야 밖 관점은 내 축에 안 걸립니다.

---

## A. 포맷 축 — 따라할 수 있는 것

**1 = 극 A, 5 = 극 B.** 양극단이 **둘 다 매력적**이어야 축입니다.

아래 여섯 줄은 **출발점**입니다. 내 분야에 안 맞으면 지우고 내 걸로 바꾸세요.

| 축 | ← 극 A | 극 B → | 내 위치 | 근거 (내가 쓴 문장) |
|---|---|---|---|---|
| 시작점 | 이미 아는 것에서 | 작고 낯선 것에서 | | |
| 목소리 | 해설자가 말한다 | 당사자가 말한다 | | |
| 해설 위치 | 설명 먼저 | 장면 먼저, 설명 나중 | | |
| 화면 의존도 | 봐야 이해된다 | 들어도 완결된다 | | |
| 대조 구조 | 하나만 본다 | 둘을 나란히 놓는다 | | |
| 반응의 노출 | 결과만 보여준다 | 반응까지 보여준다 | | |

> [!warning] 한쪽으로 몰리면 축이 아닙니다
> 내 위치가 전부 4~5로 나왔다면, 레퍼런스를 **이미 그 기준으로 골랐기 때문**입니다.
> 반대쪽 극이 조금도 매력적으로 안 보이는 줄은 축이 아니라 **선언**입니다.
> 축에서 빼고 제작 규칙으로 내리세요. 축은 고민하는 자리지 결심하는 자리가 아닙니다.

**쓰는 법:** 새 레퍼런스를 만나면 여섯 칸에 점을 찍습니다.
**내 위치와 먼 칸이 배울 곳**입니다. 전부 비슷하면 이미 아는 것이라 가져올 게 없습니다.

## B. 내용 축 — 참고할 관점

| 축 | ← 극 A | 극 B → | 내 위치 | 근거 (내가 쓴 문장) |
|---|---|---|---|---|
| 공개의 수위 | 다 보여준다 | 가려서 보여준다 | | |
| 관계의 거리 | 관찰자로 본다 | 당사자로 겪는다 | | |
| 맞음의 처리 | 맞은 것만 보여준다 | 빗나간 것도 보여준다 | | |
| 시간 | 완성된 이야기 | 되어가는 중 | | |
| | | | | |

> **한 값으로 안 잡히는 축은 `갈림` 이라고 쓰세요.**
> 호라이즌마다 값이 반대인 경우가 있습니다. 그건 흠이 아니라 [[_호라이즌]] 의 긴장이
> 축에 비친 것이고, **콘텐츠가 나오는 자리**입니다.

**쓰는 법:** 관점을 읽은 뒤 [[_관계-연산자]] 의 다섯 단어 중 하나를 고릅니다.
**고를 수 없으면 아직 안 읽은 것입니다.** 한 번 더 보세요.

## 취향 축과 겹치지 않습니다

[[_Ontology-MOC]] 의 축은 **내가 어떻게 만드는가**입니다.
여기 축은 **남이 만든 걸 어떻게 볼 것인가**입니다.

둘이 부딪히면 지우지 말고 기록하세요. 예를 들어 취향 축이 "채워서 말함" 인데
포맷 축이 "장면 먼저, 설명 나중" 이면 같이 가기 어렵습니다. 그 어긋남이 내 작업의 특징입니다.

---

> [!example] 강사 예시 (씩씩)
> 포맷 축 `해설 위치` 를 4(장면 먼저)로 잡았는데 취향 축 `밀도` 는 4(채워서 말함)였습니다.
> 모순이라 지우려다 그대로 뒀더니, 그게 "자막은 비우고 설명은 캡션으로" 라는 규칙이 됐습니다.
